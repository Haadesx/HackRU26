We are building a system for patient's to track and manage their medication. We want to target this towards the elderly for this iteration. 

The user can scan their medication labels and we put it together as a tentative presciption. They are then able to edit it so that their medication schedule is finalized. This is then stored in a database.

When the user is supposed to take the medicine, it needs to give reminders. When the user picks up the medicine to take, they can scan it and we retrieve its name and dosage and accordingly update the user history as well as the database quantity available. 

A caregiver also can have access to the data.

When the pills are about to run out, it should help set up an appointment for a refill and refills should be logged.

We can verify the medicines against openFDA when enetering in the presciption to verify.
